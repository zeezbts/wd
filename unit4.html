1. What Is Client-Side Scripting?

A website usually uses three main core technologies working together:

Technology Purpose
HTML Creates the foundational structure of a web page
CSS Adds colors, customized layout, and visual design
JavaScript Adds dynamic actions and live user interactivity

Client-side scripting means that a program runs directly inside the user’s local web browser instead of relying constantly on the external server.

For example, when you perform any of these actions, JavaScript is likely executing in the background:

  • Click a button
  • Open a drop-down navigation menu
  • Submit a form interface
  • See an instantaneous validation error message
  • Dynamically alter page colors
  • Use an interactive calculator tool directly on a web page

Interactive Client-Side Example

Test out this basic embedded sample implementation directly below:

Welcome Student

<!DOCTYPE html>
<html>
<body>

  <h1 id="title">Welcome</h1>
  <button onclick="changeTitle()">Change Text</button>

  <script>
    function changeTitle() {
      document.getElementById("title").textContent = "Hello, JavaScript!";
    }
  </script>

</body>
</html>

Client-Side vs. Server-Side Scripting

Client-Side Scripting Server-Side Scripting
Runs directly locally within your browser. Runs remotely on a web server setup.
Gives instant, snappy responses. Processes sensitive data and user accounts safely.
Changes page content without full reloads. Communicates securely with underlying databases.
Commonly utilizes JavaScript framework standards. Uses technologies such as Node.js, PHP, Python, or Java.

Note: JavaScript is unique because it can be used on both the client side and the server side!

2. What Is JavaScript?

JavaScript is a lightweight programming language used to make web pages highly interactive and dynamically updated.

JavaScript has the capability to:

  • Display pop-up alerts and logs
  • Calculate equations and numeric data
  • Change HTML content structural texts dynamically
  • Modify CSS styling formats on the fly
  • Validate user forms before processing submission data
  • Respond instantly to mouse movements, clicks, and keystrokes
  • Execute repeating tasks and evaluate structural conditional decisions

Simple Output Commands

Displaying data using developer tool logs:

console.log("Hello, JavaScript!");

Displaying basic pop-up interface prompt windows:

alert("Welcome to my website!");

JavaScript Is Case-Sensitive

JavaScript treats uppercase and lowercase letters as completely unique keywords.

let name = "Ali";

console.log(name); // Correct: outputs "Ali"
console.log(Name); // Error: "Name" is not defined

Comments in JavaScript

Comments are non-executing descriptive text notes used to assist developers with documentation.

Single-Line Comment: Use double slashes //

// This is a single-line comment
let age = 20;

Multiple-Line Comment: Wrap content within /* */ markers

/*
  This is a multiple-line comment.
  It can safely contain several lines.
*/
let score = 90;

3. How to Develop JavaScript

There are three main development approaches to append scripts onto web pages:

Method 1: Inline Attribute Scripting

<button onclick="alert('Hello!')">Click Me</button>

*Avoid this in larger scaled projects because it clutters structural HTML markup.

Method 2: Embedded Internal Script Tags

<script>
  console.log("JavaScript is running internal.");
</script>

Method 3: External Script Files (Best Practice)

This is highly recommended to split programmatic operational tasks away from actual presentation setups.

index.html
<!DOCTYPE html>
<html>
<head>
  <title>My JavaScript Page</title>
</head>
<body>

  <h1 id="heading">Hello</h1>
  <button id="button">Click Me</button>

  <script src="script.js"></script>
</body>
</html>
script.js
let button = document.getElementById("button");

button.onclick = function () {
  document.getElementById("heading").textContent = "Button clicked!";
};

5. Variables

A variable is a named container used to store data.

let studentName = "David";

Here:

  • let creates the variable
  • studentName is the variable name
  • "David" is the value

Creating Variables With let

Use let when the value may change.

let score = 50;
score = 75;
console.log(score);

Output: 75

The value of score changed from 50 to 75.

Creating Variables With const

Use const when the value should not be changed.

const schoolName = "Green Valley School";
console.log(schoolName);

This is not allowed:

const age = 20;
age = 21; // Error

Use const by default when you do not need to change the value.

The Older var Keyword

var is an older way to create variables.

var color = "blue";

Modern JavaScript usually uses let and const instead of var.

Rules for Variable Names

Variable names:

  • Can contain letters
  • Can contain numbers, but not at the beginning
  • Can contain _ and $
  • Cannot contain spaces
  • Should describe the stored value
  • Are case-sensitive

Valid names:

let studentName;
let age2;
let total_price;

Invalid names:

let 2age;       // Cannot start with a number
let student name; // Cannot contain spaces
let let;        // Cannot use a reserved word

A common style is camelCase:

let firstName = "Maria";
let totalMarks = 450;

6. JavaScript Data Types

A data type describes the kind of information stored in a variable.

String

A string is text.

let name = "Ahmed";
let message = 'Hello';

Strings can use single or double quotation marks.

Number

A number can be an integer or decimal.

let age = 25;
let price = 19.99;

Boolean

A Boolean has only two values:

let isOnline = true;
let isComplete = false;

Booleans are useful for conditions.

Undefined

A variable is undefined when it has been created but has no value.

let result;
console.log(result);

Output: undefined

Null

null means that a value is intentionally empty.

let selectedColor = null;

Array

An array stores multiple values in one variable.

let fruits = ["Apple", "Banana", "Orange"];

Array positions start at 0.

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Banana
console.log(fruits[2]); // Orange

Object

An object stores information using property names and values.

let student = {
  name: "Ali",
  age: 18,
  grade: "A"
};

console.log(student.name);
console.log(student.age);

7. Operators

Operators are symbols used to perform actions.

Arithmetic Operators

let a = 10;
let b = 3;

console.log(a + b); // Addition: 13
console.log(a - b); // Subtraction: 7
console.log(a * b); // Multiplication: 30
console.log(a / b); // Division: 3.333...
console.log(a % b); // Remainder: 1

The % operator is called the modulus or remainder operator.

Increment and Decrement

let number = 5;

number++;
console.log(number); // 6

number--;
console.log(number); // 5
  • ++ increases a value by 1
  • -- decreases a value by 1

Assignment Operators

let score = 10;

score += 5; // score becomes 15
score -= 3; // score becomes 12
score *= 2; // score becomes 24
score /= 4; // score becomes 6

8. Functions

A function is a reusable block of code.

Functions help you:

  • Avoid repeating code
  • Organize your program
  • Make code easier to understand
  • Perform a specific task

Creating a Function

function sayHello() {
  console.log("Hello!");
}

This creates a function called sayHello.

Calling a Function

A function runs when it is called.

sayHello();

Output: Hello!

Function With a Parameter

A parameter is information given to a function.

function greet(name) {
  console.log("Hello, " + name);
}

greet("Aisha");
greet("Robert");

Output:
Hello, Aisha
Hello, Robert

The function can work with different names.

Function With Multiple Parameters

function introduce(name, age) {
  console.log(`My name is ${name} and I am ${age} years old.`);
}

introduce("Ali", 20);

Function With a Return Value

A function can send a result back using return.

function addNumbers(a, b) {
  return a + b;
}

let answer = addNumbers(4, 6);
console.log(answer);

Output: 10

The returned value can be stored in a variable.

Arrow Functions

An arrow function is a shorter way to write a function.

const multiply = (a, b) => {
  return a * b;
};

console.log(multiply(3, 4));

For a simple function, it can be even shorter:

const square = number => number * number;

console.log(square(5));

9. Conditions

Conditions allow a program to make decisions.

For example:

  • If the user is logged in, show the account page.
  • If the password is incorrect, show an error.
  • If the marks are high, show a good grade.

The if Statement

let temperature = 30;

if (temperature > 25) {
  console.log("It is hot.");
}

The message is shown only when the condition is true.

The if...else Statement

let age = 16;

if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are a minor.");
}

If the condition is true, the first block runs. Otherwise, the else block runs.

The else if Statement

Use else if when there are several possible conditions.

let marks = 82;

if (marks >= 90) {
  console.log("Grade A+");
} else if (marks >= 80) {
  console.log("Grade A");
} else if (marks >= 70) {
  console.log("Grade B");
} else if (marks >= 50) {
  console.log("Grade C");
} else {
  console.log("Fail");
}

Comparison Operators

let x = 10;
let y = 5;

x == y;   // Equal in value
x === y;  // Equal in value and type
x != y;   // Not equal in value
x !== y;  // Not equal in value or type
x > y;    // Greater than
x < y;    // Less than
x >= y;   // Greater than or equal to
x <= y;   // Less than or equal to

Example

let number = 10;

if (number === 10) {
  console.log("The number is 10.");
}

It is usually safer to use === because it checks both the value and the data type.

Logical Operators

AND: &&

Both conditions must be true.

let age = 25;
let hasTicket = true;

if (age >= 18 && hasTicket === true) {
  console.log("You can enter.");
}

OR: ||

At least one condition must be true.

let day = "Saturday";

if (day === "Saturday" || day === "Sunday") {
  console.log("It is the weekend.");
}

NOT: !

Changes true to false or false to true.

let isClosed = false;

if (!isClosed) {
  console.log("The shop is open.");
}

Ternary Operator

The ternary operator is a short form of if...else.

let age = 20;
let message = age >= 18 ? "Adult" : "Minor";
console.log(message);

This means: If age is 18 or more, use "Adult"; otherwise, use "Minor".

Switch Statement

A switch statement is useful when comparing one value with several options.

let day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;

  case "Friday":
    console.log("Almost the weekend");
    break;

  case "Saturday":
  case "Sunday":
    console.log("Weekend");
    break;

  default:
    console.log("A normal weekday");
}

The break command stops the switch after a matching case is found.

10. Loops and Repetition

A loop repeats code.

Loops are useful for:

  • Displaying a list of names
  • Counting numbers
  • Processing data
  • Repeating an action
  • Going through an array

for Loop

Use a for loop when you know how many times to repeat something.

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

This has three parts:

for (start; condition; update) {
  // Code to repeat
}

In the example:

  • let i = 1 starts the counter.
  • i <= 5 checks the condition.
  • i++ increases the counter.

Output:
1
2
3
4
5

Counting Backward

for (let i = 5; i >= 1; i--) {
  console.log(i);
}

Output:
5
4
3
2
1

while Loop

A while loop runs as long as its condition is true.

let number = 1;

while (number <= 5) {
  console.log(number);
  number++;
}

The counter must change. Otherwise, the loop may never stop.

Infinite Loop Example

// Do not run this example

let number = 1;

while (number <= 5) {
  console.log(number);
  // number++ is missing
}

Because number never changes, the condition remains true forever.

do...while Loop

A do...while loop always runs at least once.

let number = 10;

do {
  console.log(number);
  number++;
} while (number < 5);

Even though number < 5 is false, the program prints 10 once.

for...of Loop

Use for...of to read values from an array.

let colors = ["Red", "Green", "Blue"];

for (let color of colors) {
  console.log(color);
}

Output:
Red
Green
Blue

forEach()

forEach() also runs code for every array item.

let numbers =;

numbers.forEach(function(number) {
  console.log(number);
});

Using an arrow function:

numbers.forEach(number => {
  console.log(number);
});

break

The break statement stops a loop.

for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}

Output:
1
2
3
4

continue

The continue statement skips the current repetition and continues with the next one.

for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }
  console.log(i);
}

Output:
1
2
4
5

11. Arrays

An array stores several values in one variable.

let fruits = ["Apple", "Banana", "Mango"];

Array indexes start at 0.

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Banana
console.log(fruits[2]); // Mango

Finding the Array Length

console.log(fruits.length);

Output: 3

Adding an Item

fruits.push("Orange");
console.log(fruits);

Removing the Last Item

fruits.pop();

Adding an Item at the Beginning

fruits.unshift("Grapes");

Removing the First Item

fruits.shift();

Looping Through an Array

let students = ["Ali", "Sara", "John"];

for (let i = 0; i < students.length; i++) {
  console.log(students[i]);
}

12. Working With HTML

JavaScript can access and change HTML elements. This is called working with the DOM, or Document Object Model.

Finding an Element by ID

HTML

<p id="message">Old message</p>

JavaScript

let paragraph = document.getElementById("message");
paragraph.textContent = "New message";

Changing CSS With JavaScript

HTML

<h1 id="title">Hello</h1>

JavaScript

let title = document.getElementById("title");
title.style.color = "blue";
title.style.fontSize = "40px";

Reading Input From a User

HTML

<input id="nameInput" type="text">
<button onclick="showName()">Submit</button>
<p id="result"></p>

JavaScript

function showName() {
  let name = document.getElementById("nameInput").value;
  document.getElementById("result").textContent = "Hello, " + name;
}

The .value property reads what the user typed.

13. Events

An event is an action that happens on a web page.

Examples include:

  • Clicking a button
  • Moving the mouse
  • Typing on the keyboard
  • Submitting a form
  • Loading a page

Using onclick

<button onclick="sayHello()">Click Me</button>

<script>
  function sayHello() {
    alert("Hello!");
  }
</script>

Using addEventListener

This is a more modern and flexible method.

HTML

<button id="myButton">Click Me</button>

JavaScript

let button = document.getElementById("myButton");

button.addEventListener("click", function() {
  alert("The button was clicked.");
});

14. Complete Simple JavaScript Example

This example checks whether a number is positive, negative, or zero.

<!DOCTYPE html>
<html>
<head>
  <title>Number Checker</title>
</head>
<body>

  <h1>Number Checker</h1>

  <input id="numberInput" type="number">
  <button id="checkButton">Check Number</button>

  <p id="result"></p>

  <script>
    let input = document.getElementById("numberInput");
    let button = document.getElementById("checkButton");
    let result = document.getElementById("result");

    button.addEventListener("click", function() {
      let number = Number(input.value);

      if (number > 0) {
        result.textContent = "The number is positive.";
      } else if (number < 0) {
        result.textContent = "The number is negative.";
      } else {
        result.textContent = "The number is zero.";
      }
    });
  </script>

</body>
</html>

How This Program Works

  • The user enters a number.
  • The button is clicked.
  • JavaScript reads the input.
  • Number() converts the input into a number.
  • The if...else if...else structure checks the number.
  • The result is displayed on the page.

15. Another Example: Simple Calculator

<!DOCTYPE html>
<html>
<head>
  <title>Simple Calculator</title>
</head>

  <input id="firstNumber" type="number" placeholder="First number">
  <input id="secondNumber" type="number" placeholder="Second number">

16. Common JavaScript Errors

Missing Quotation Marks

Incorrect:

let name = Ali;

Correct:

let name = "Ali";

Using an Undeclared Variable

Incorrect:

console.log(username);

If username was never created, JavaScript will show an error.

Correct:

let username = "Ali";
console.log(username);

Incorrect Capitalization

Incorrect:

Console.log("Hello");

Correct:

console.log("Hello");

JavaScript is case-sensitive.

Forgetting to Increase a Loop Counter

Incorrect:

let i = 1;

while (i <= 5) {
  console.log(i);
}

Correct:

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

Using = Instead of ===

The = operator assigns a value.

let age = 18;

The === operator compares values.

if (age === 18) {
  console.log("Correct age");
}
