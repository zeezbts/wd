2. JavaScript Objects

An object stores data in the form of key-value pairs.

let student = {
    name: "Anita",
    age: 21,
    course: "JavaScript"
};

Here, name, age, and course are properties, while "Anita", 21, and "JavaScript" are property values.

Accessing Object Properties

Dot Notation:

console.log(student.name);
console.log(student.age);

Bracket Notation:

console.log(student["name"]);

Bracket notation is useful when the property name is dynamically stored in a variable.

let property = "course";
console.log(student[property]);

Modifying Properties

Changing Properties:

student.age = 22;
student.course = "Advanced JavaScript";

Adding Properties:

student.email = "anita@example.com";

Deleting Properties:

delete student.email;

3. Methods in Objects

A function stored inside an object is called a method.

let user = {
    name: "Ravi",

    greet: function() {
        console.log("Hello, " + this.name);
    }
};

user.greet();

The keyword this refers to the object that is calling the method.

Modern Method Syntax

let user = {
    name: "Ravi",

    greet() {
        console.log(`Hello, ${this.name}`);
    }
};

4. Object Destructuring

Destructuring extracts properties from an object cleanly into separate variables.

let student = {
    name: "Priya",
    age: 20
};

let { name, age } = student;

console.log(name);
console.log(age);

You can also rename properties during extraction:

let { name: studentName } = student;

console.log(studentName);

5. Object Spread Operator

The spread operator (...) copies object properties over into a new object structure.

let person = {
    name: "Amit",
    age: 25
};

let updatedPerson = {
    ...person,
    city: "Mumbai"
};

console.log(updatedPerson);

It can also be used to selectively update properties:

let changedPerson = {
    ...person,
    age: 26
};

6. Built-in Object Methods

Object.keys()

Returns an array containing the property names (keys).

let product = {
    name: "Laptop",
    price: 50000
};

console.log(Object.keys(product)); 
// Output: ["name", "price"]

Object.values()

Returns an array containing the actual property values.

console.log(Object.values(product));
// Output: ["Laptop", 50000]

Object.entries()

Returns multi-dimensional arrays consisting of nested key-value pairs.

console.log(Object.entries(product));

Object.assign()

Copies properties from one or more source objects to a target object.

let first = { a: 1 };
let second = { b: 2 };

let combined = Object.assign({}, first, second);
console.log(combined);

7. JavaScript Own Objects

An own object usually means an object created by the programmer. Its properties are directly attached to that object.

let book = {
    title: "JavaScript Guide",
    author: "John",
    price: 400
};

The properties title, author, and price are own properties of book.

Checking an Own Property

console.log(book.hasOwnProperty("title")); 
// Output: true

Modern syntax alternative:

console.log(Object.hasOwn(book, "price"));

User-Defined Constructor

function Employee(name, salary) {
    this.name = name;
    this.salary = salary;
}

let employee1 = new Employee("Ravi", 30000);

console.log(employee1.name);

User-Defined Class

class Employee {
    constructor(name, salary) {
        this.name = name;
        this.salary = salary;
    }

    displayDetails() {
        console.log(`${this.name} earns ${this.salary}`);
    }
}

let employee = new Employee("Anita", 40000);
employee.displayDetails();

9. Arrays as Objects

An array stores multiple values sequentially. In JavaScript, arrays are technically specialized objects with numeric keys called indexes.

let numbers = [10, 5, 30, 20];

Array indexes start from 0.

console.log(numbers[0]);  // Output: 10
console.log(numbers.length); // Output: 4

Common Array Methods

numbers.push(40);       // Add at the end
numbers.pop();          // Remove from the end
numbers.unshift(5);     // Add at the beginning
numbers.shift();        // Remove from the beginning

map()

Creates a new array by performing a function on every element of the source array.

let numbers =;

let squares = numbers.map(function(number) {
    return number * number;
});

console.log(squares); // Output: [1, 4, 9, 16]

filter()

Returns a new array containing elements that pass a specific conditional check.

let ages =;

let adults = ages.filter(function(age) {
    return age >= 18;
});

console.log(adults); // Output: [18, 25, 30]

reduce()

Reduces an array down to a single value by executing a callback on each element.

let numbers =;

let total = numbers.reduce(function(sum, number) {
    return sum + number;
}, 0);

console.log(total); // Output: 60

Sorting Arrays

Strings:

let names = ["Zara", "Amit", "John"];
names.sort();

console.log(names); // Output: ["Amit", "John", "Zara"]

Numbers (Ascending Order):

let numbers =;

numbers.sort(function(a, b) {
    return a - b;
});

console.log(numbers); // Output: [5, 25, 40, 100]

Numbers (Descending Order):

numbers.sort(function(a, b) {
    return b - a;
});

console.log(numbers); // Output: [100, 40, 25, 5]

Important: Without an explicit comparison function, numbers are sorted alphabetically as if they were strings (e.g., "100" comes before "25").

10. The DOM

DOM stands for Document Object Model.

The browser converts an incoming HTML page into a live tree of objects. JavaScript targets this tree structure to read and dynamically adjust the page view.

Example HTML breakdown:

<html>
    <body>
        <h1>Welcome</h1>
        <p>Hello</p>
    </body>
</html>

The resulting DOM structures contain objects that represent:

  • The root document
  • HTML elements
  • Attributes (classes, IDs, hrefs)
  • Text content
  • Events

Using JavaScript interacting with the DOM, you can safely:

  • Select HTML elements dynamically.
  • Update written text nodes.
  • Alter CSS visual styles.
  • Add or delete structural elements.
  • Catch and handle user interactions.
  • Validate form field inputs before submission.

11. Selecting DOM Elements

getElementById()

Targets exactly one explicit element using its unique ID attribute.

<p id="message">Old text</p>

<script>
let message = document.getElementById("message");
message.textContent = "New text";
</script>

getElementsByClassName()

Selects all matching document elements containing a specific class name. Returns an HTMLCollection.

let boxes = document.getElementsByClassName("box");

getElementsByTagName()

Selects all document elements matching a standard tag name.

let paragraphs = document.getElementsByTagName("p");

querySelector()

Returns the very first element matching a standard CSS selector expression.

let heading = document.querySelector("h1");  // Tag selector
let box = document.querySelector(".box");     // Class selector
let item = document.querySelector("#item");   // ID selector

querySelectorAll()

Returns all elements matching the given CSS selector inside a static NodeList, allowing iteration.

let paragraphs = document.querySelectorAll("p");

paragraphs.forEach(function(paragraph) {
    paragraph.style.color = "blue";
});

12. Changing HTML Content

textContent

Alters or updates plain text exclusively, ignoring structural HTML entities.

document.getElementById("message").textContent = "This is new text.";

innerHTML

Parses standard HTML tags, allowing structural changes directly inside the target node.

document.getElementById("message").innerHTML = "<strong>Important message</strong>";

Security Note: Always prefer textContent when rendering plain text data strings. Using innerHTML with unvalidated input from users leaves applications exposed to Cross-Site Scripting (XSS) injection attacks.

Input Values

To read or update interactive form inputs, use the .value property instead of text properties.

let username = document.getElementById("username").value;

13. Changing CSS with JavaScript

Using the style Property

Modifies inline styles directly on an individual element node.

let heading = document.getElementById("heading");

heading.style.color = "red";
heading.style.backgroundColor = "yellow";
heading.style.fontSize = "30px";

Using Classes

Leverages class definitions within CSS rules to style elements efficiently.

<style>
.highlight {
    color: white;
    background-color: green;
    padding: 10px;
}
</style>

<p id="message">Hello</p>

Manipulate those classes cleanly using classList methods:

let message = document.getElementById("message");

message.classList.add("highlight");    // Adds the class
message.classList.remove("highlight"); // Removes the class
message.classList.toggle("highlight"); // Toggles class state

Best Practice: Managing styles with CSS classes via classList keeps presentation separated from logic, making maintenance much easier than inline assignments.

14. Creating and Removing DOM Elements

Creating an Element

Instantiates a new element structure in memory and appends it to the DOM tree node hierarchy.

let paragraph = document.createElement("p");

paragraph.textContent = "This paragraph was created using JavaScript.";

document.body.appendChild(paragraph);

Adding an Element to a Specific Parent

<ul id="list"></ul>

<script>
let listItem = document.createElement("li");
listItem.textContent = "New item";

document.getElementById("list").appendChild(listItem);
</script>

Removing an Element

Removes a node structure entirely from the running layout context tree.

listItem.remove();

Legacy standard variant for older runtime environments:

let item = document.getElementById("oldItem");
item.parentNode.removeChild(item);

15. DOM Events

An event represents an active lifecycle step or user action happening inside the browser viewport context.

Common event types include:

  • click / dblclick
  • mouseover / mouseout
  • keydown / keyup
  • focus / blur
  • input / change
  • submit / load

Using addEventListener()

<button id="button">Click Me</button>
<p id="output"></p>

<script>
let button = document.getElementById("button");

button.addEventListener("click", function() {
    document.getElementById("output").textContent = "Button clicked.";
});
</script>

Event Object

Callback routines receive a tracking object argument describing the target properties of that interaction.

document.addEventListener("keydown", function(event) {
    console.log("Key pressed:", event.key);
});

Preventing Default Action

Stops default runtime routines from terminating execution tracking loops automatically.

form.addEventListener("submit", function(event) {
    event.preventDefault();
});

This avoids immediate form submissions and subsequent page refreshes, permitting safe inline client-side validation logic.

25. Basic Form Validation

Validation processes interrupt structural pipeline errors client-side before sending missing data fragments over backend endpoints.

<form id="myForm">
    <input type="text" id="username">
    <button type="submit">Submit</button>
</form>

<script>
document.getElementById("myForm").addEventListener("submit", function(event) {
    event.preventDefault(); // HALT form submission routing loops

    let username = document.getElementById("username").value.trim(); // Trim spaces

    if (username === "") {
        alert("Username is required.");
    } else {
        alert("Form is valid.");
    }
});
</script>

28. Complete Form Validation Example

The code script below wires real-time structural processing to display descriptive error state markers inline cleanly underneath input tags without intrusive alert banners.

<form id="registrationForm">
    <label>Email:</label>
    <input type="text" id="email">
    <div id="emailError" class="error"></div>

    <label>Password:</label>
    <input type="password" id="password">
    <div id="passwordError" class="error"></div>

    <button type="submit">Register</button>
</form>

<script>
let form = document.getElementById("registrationForm");

form.addEventListener("submit", function(event) {
    event.preventDefault();

    let email = document.getElementById("email").value.trim();
    let password = document.getElementById("password").value;

    let emailError = document.getElementById("emailError");
    let passwordError = document.getElementById("passwordError");

    // Reset error text
    emailError.textContent = "";
    passwordError.textContent = "";

    let valid = true;
    let emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

    if (email === "") {
        emailError.textContent = "Email is required.";
        valid = false;
    } else if (!emailPattern.test(email)) {
        emailError.textContent = "Enter a valid email address.";
        valid = false;
    }

    if (password === "") {
        passwordError.textContent = "Password is required.";
        valid = false;
    } else if (password.length < 8) {
        passwordError.textContent = "Password must contain at least 8 characters.";
        valid = false;
    }

    if (valid) {
        alert("Registration successful.");
        form.reset();
    }
});
</script>
